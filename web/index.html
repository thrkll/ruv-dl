Hvað er ruv-dl?

ruv-dl er opinn hugbúnaður sem hefur enga tengingu við RÚV.

Engar vafrakökur eru notaðar og notkun þín er ekki rakin. Allt gerist í vafranum þínum og efnið kemur milliliðalaust frá RÚV. Ein önnur tenging er við Cloudflare (1.1.1.1) til að sýna þér frá hvaða landi þú ert að tengjast.

Hvað gerist þegar ég ýti á Sækja?

Vafrinn þinn sækir efnið frá RÚV á sama hátt og spilarinn á ruv.is gerir þegar þú horfir. Munurinn er sá að í stað þess að spila myndefnið setur síðan það saman í eina skrá og vistar hana á tölvunni þinni. Enginn netþjónn á vegum ruv-dl kemur við sögu og efnið fer því ekki um hendur neins annars en RÚV.

Af hverju virkar þetta eiginlega bara á Íslandi?

RÚV ræður hvaðan má horfa á efnið. Þar sem niðurhalið fer fram á þinni eigin tengingu gilda sömu reglur og á ruv.is - ef þú getur horft á efnið þar, þá geturðu sótt það hér.

Og er þetta bara löglegt?

Já (líklega). Skv. höfundaréttarlögum er einstaklingum heimilt að gera eintök af birtu verki til einkanota, enda sé það ekki gert í fjárhagslegum tilgangi. Ekki má nota slík eintök í neinu öðru skyni. En hvað veit ég? Þetta er á milli þín og RÚV 🤝 Þú berð sjálf/ur ábyrgð á því hvernig þú notar efnið og ef þú ert í vafa er best að kynna sér skilmála RÚV.

Hvernig getur vefsíða sótt efni af öðrum vef?

Vafrar banna vefsíðum oft að lesa gögn af öðrum vefjum. Vefþjónn getur þó veitt leyfi fyrir því með svokölluðum CORS-hausum (Cross-Origin Resource Sharing). Þjónar RÚV senda hausinn Access-Control-Allow-Origin, sem leyfir öðrum vefsíðum að lesa efnið, til dæmis svo hægt sé að spila það á öðrum vefsíðum. Ef RÚV breytir þeirri stillingu hættir þessi síða að virka. En pls ekki. 🙏

Hvernig er efnið sett saman?

RÚV sendir efni út með HLS (HTTP Live Streaming) og .m3u8 playlist sem vísar á hundruð stuttra búta, um sex sekúndur hver, í mismunandi gæðum. ruv-dl les listann, sækir bútana í réttri röð, nokkra í einu, og breytir þeim úr MPEG-TS í MP4 með js-safninu mux.js og sérsmíðuðum muxing kóða. Mynd og hljóð eru afrituð óbreytt og ekki endurkóðuð með neinum hætti, svo engin gæði tapast.

Hvernig er skráin vistuð?

Í Chrome og Edge (Chromium-vafrar) er skráin skrifuð beint á diskinn á tölvunni þinni í gegnum File System Access API, svo efnið tekur lítið minni í vafranum. Aðrir vafrar (Firefox, Safari o.fl.) safna skránni saman í minni (sem Blob) og henni er svo halað niður eins og hverri annarri skrá.

Öryggi

Síðan er bundin öryggisstefnu (Content Security Policy) sem leyfir aðeins tengingar við RÚV (*.ruv.is og *.akamaized.net) og Cloudflare. Föst útgáfa af mux.js er sótt og vafrinn ber það saman við þekkt fingrafar (Subresource Integrity) áður en það fær að keyra. Allur kóðinn er aðgengilegur á thrkll/ruv-dl.

What is ruv-dl?

ruv-dl is an independent open-source project, not affiliated with RÚV. For personal use only.

No cookies are used and nothing is tracked. Everything happens in your browser, and the content comes straight from RÚV with nothing in between. The only other connection is to Cloudflare (1.1.1.1), to show you which country you are connecting from.

Shortcut

On ruv.is? Add -dl after ruv in the address and you land right here, ready to download: www.ruv-dl.is/sjonvarp/spila/…

What happens when I press Download?

Your browser fetches the content from RÚV the same way the player on ruv.is does when you watch. The difference is that instead of playing the video, this page joins it into one file and saves it on your computer. No ruv-dl server is involved, so the content never passes through anyone but RÚV.

Why does this only work in Iceland, anyway?

RÚV decides where its content can be watched. Because the download runs over your own connection, the same rules apply as on ruv.is - if you can watch it there, then you can download it here.

So is this even legal?

Yes (probably). Under copyright law, individuals may make copies of a published work for private use only, as long as it is not done for financial gain. Such copies may not be used for anything else. But what do I know? This is between you and RÚV 🤝 You are responsible for how you use the content, and if in doubt, it is best to check RÚV's terms.

How can a website fetch content from another site?

Browsers often stop websites from reading data from other sites. A server can allow it with so-called CORS headers (Cross-Origin Resource Sharing). RÚV's servers send the Access-Control-Allow-Origin header, which lets other websites read the content, for example so it can be played on other websites. If RÚV changes that setting, this page stops working. But please don’t. 🙏

How is the file put together?

RÚV streams its content with HLS (HTTP Live Streaming) and a .m3u8 playlist that points to hundreds of short segments, about six seconds each, in different qualities. The page reads the playlist, fetches the segments in order, a few at a time, and converts them from MPEG-TS to MP4 with the JS library mux.js and custom-built muxing code. Video and audio are copied as they are and not re-encoded in any way, so no quality is lost.

How is the file saved?

In Chrome and Edge the file is then written straight to the disk on your computer through the File System Access API, so the content takes up little memory in the browser. Other browsers (Firefox, Safari etc.) collect the file in memory (as a Blob), which is then downloaded like any other file.

Security

The page is bound by a Content Security Policy that only allows connections to RÚV (*.ruv.is and *.akamaized.net) and Cloudflare. A fixed version of mux.js is loaded, and the browser checks it against a known fingerprint (Subresource Integrity) before it may run. All the code is open at thrkll/ruv-dl.
